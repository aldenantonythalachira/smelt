Everyone was screaming about Svelte, so I just tried building a project with this framework.

Three hours later, I get it. 

No virtual DOM. No useState. No useEffect. No dependency arrays. Just let count = 0 and $: doubled = count * 2 — and it works.

Bundles are tiny.  HMR is instant.  The code is half of what React would've been.

It's not "React but nicer." It's a different philosophy — compile away the framework.

Verdict: Svelte didn't live up to the hype. It was the hype. 🤩
